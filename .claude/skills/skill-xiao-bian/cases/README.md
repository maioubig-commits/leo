## 狀態標記

| 標記 | 意義 |
|---|---|
| 🔴 進行中 | 有活躍的往來或期限壓力 |
| 🟡 偵查中 | 刑事案件偵查階段 |
| 🟢 監控中 | 無立即動作，定期追蹤 |
| ⚪ 已結案 | 移至下方已結案區 |

## 案件檔標準格式

```markdown

status: 進行中 | 偵查中 | 監控中 | 已結案
opened: YYYY-MM-DD
escalation: 綠 | 黃 | 紅   # 依 SKILL.md 升級觸發條件判定
```
