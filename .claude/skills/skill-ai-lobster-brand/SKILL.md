## 套用規則（必做）

### 1. PPT 簡報
- **每一張 slide 右上角**都要貼 logo
- 預設位置與大小（16:9，寬 13.333" × 高 7.5"）：
  - 位置：`Inches(12.55), Inches(0.15)`
  - 尺寸：`width=Inches(0.6), height=Inches(0.6)`
- 深色封面/結尾頁也要貼（白底 logo 會自然襯出來）

### 2. PDF / Word 文件
- 文件首頁頁首右上角貼 logo（與標題同一行 / 上方）
- 多頁文件：每頁頁首右上角都要 logo（用 header 設定）
- Logo 大小：約 1.5–2cm，與標題字高相當

### 3. 海報 / 廣告 / 社群素材
- Logo 一定出現（角落或底部均可，視構圖）
- 至少要看得清楚不被切到

### 4. 影片
- 片頭：3 秒 logo + 「AI數字員工龍蝦學院」字幕
- 片尾：3-5 秒品牌結束畫面（logo + 訂閱/聯絡資訊）
- 角落浮水印（選用）：右上角半透明 logo

## Python 程式碼範本

```python
from pathlib import Path
from pptx.util import Inches

# 用家目錄推導，不要寫死別人的機器路徑
LOGO_PATH = str(Path.home() / ".claude/skills/skill-ai-lobster-brand/logo.png")

def add_logo(slide):
    """每張 slide 右上角貼 logo,16:9 簡報用。"""
    slide.shapes.add_picture(
        LOGO_PATH,
        Inches(12.55), Inches(0.15),
        width=Inches(0.6), height=Inches(0.6),
    )
```
