## 一、 人类三步极简安装指引（只需 10 秒）

### 方案 A：在聊天窗口中直接导入（最简单，适用于 Claude / ChatGPT / Cursor 等）
1. 选中本文件夹中的两个核心文件：`AGENT_INSTALLER.md` 和 `SKILL.md`；
2. 直接拖入对话框中，并发送一句话：  
   `“请严格按照 AGENT_INSTALLER.md 的指示，完成技能装载并激活初始化。”`
3. 你的 AI 会立刻弹出震撼的【外骨骼注入成功】仪式，并为你准备好 5 条测试开火指令！

### 方案 B：在 Dify / Coze / 平台型 Agent 中一键配置
1. 打开 `SKILL.md`，全选复制其中的全部内容；
2. 粘贴到你的 Agent **“人设与系统提示词（System Prompt / Instructions）”** 中；
3. 保存发布。你的专属“人类作弊器 AI 应用”即刻上线！

### 方案 C：在 Antigravity / Claude Code 本地工程中使用
1. 直接将本文件夹复制到你的 Skill 配置目录下：  
   `~/.gemini/config/skills/human-cheat-codes/`
2. 智能体将在后台自动感知并常驻运行！
